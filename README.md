# Shughni etudes. Collection of papers on the Shughni language

This repository contains LaTeX source code for the book *Shughni Etudes* published in 2025 by Institute of Humanities, National Academy of Sciences (Kharagh, Tajikistan) and Higher School of Economics (Moscow, Russia).
It is a collection of scholarly articles published by members of the HSE research team.
